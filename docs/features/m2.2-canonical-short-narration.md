## Flow

```text
Master Story Package --validate--> resolve Short (M2.1) --language check--> offline voice
  --> narrate each master segment verbatim (existing cached narrate(), Korva worker session)
  --> timeline from PCM sample counts --> concatenated narration track
  --> SRT (existing subtitle_gen) --> quality gates --> timed manifest + report
```

```powershell
.\.venv\Scripts\python.exe scripts/master_story_short.py examples/master-story/lead-masks-1966/master_story.json `
    [--project-id ID] [--tts-provider auto|korva|windows_sapi|macos_say|piper] [--voice ...] [--rate ...] `
    [--korva-python ...] [--korva-assets ...] [--lead-in 0.3] [--gap 0.4] [--tail 0.5]
```

Exit code 0 only when every automatic gate passes; 1 otherwise (artifacts kept).
No image, video, renderer, Story Planner or Story Analyzer involvement; canonical
IDs are never re-derived from text.

Language: the package's declared language is cross-checked against the narration
(Vietnamese marks after NFD: dot below, hook above, horn, breve, đ). `vi` and `en`
only. The selected voice's locale must match; otherwise the run stops ("Blocked").
`auto` keeps the existing selector: Korva for Vietnamese when installed, native/Piper
otherwise; Korva never reads English. Nothing is translated or rewritten.

## Quality gates

| Gate | Checks |
| --- | --- |
| `segments_complete` | Beat IDs equal the plan's ordered `segment_ids`; reports missing / duplicated / unexpected |
| `text_verbatim` | Beat text equals the master segment text |
| `no_new_claims_or_sources` | Per-segment claims unchanged; union equals the format's claims; sources equal those cited by them |
| `qualifiers_and_continuity` | Status and qualifier of each carried claim equal the package; `requires_claims` rules hold; lists `human_review` rules in scope |
| `audio_measured` | WAV readable, samples/rate equal the manifest, window = samples/rate, beats ordered, track length = timeline |
| `subtitles_aligned` | Cue text inside each beat window equals the beat text; cues ordered, non-overlapping; whole SRT text = narration |
| `duration_target` | Total within the plan's target; otherwise `over_by_seconds` / `under_by_seconds` and the three longest segments |

Subtitle sentence timings are split by character share inside the measured segment
window (not word alignment). ASR (`projects/m22-short-proof/asr_manifest.py`, offline
Whisper) is a listening aid only.

## M2.2.1 — duration fix through canonical editorial selection (2026-10-22)

The six-segment Short above measured 72.68 s. Only `formats.short` (`segment_ids`,
`notes`) was changed; Master Narrative, claims, sources and the Long plan are unchanged
(verified by JSON diff). Korva speed stayed 1.05; timing policy unchanged (0.3 / 0.4 / 0.5 s).

All 45 master segments were synthesized once with the production selector/cache to
compare candidates on measured audio (`projects/m221-short-selection/measured_segments.json`;
10.0–14.3 s per segment, 573.06 s total). With fixed pauses, five segments need ≤52.6 s of
speech, so coherent options are four segments. Exhaustive search (`evaluate_candidates.py`
plus a combination scan): requiring SEG_01 first, an ending segment last, the lead masks
(CLM_012), the capsule first mentioned by SEG_03/SEG_19 and SEG_03 only right after SEG_02,
every rule-valid combination inside 50–55 s **omits SEG_02** — the only segment that
introduces the note — so SEG_19 ("Đó là điều được viết…") loses its referent. Best of
those is F below.
