## Chuẩn bị Python, Node và FFmpeg

Những lệnh sau **chưa được chạy trên Mac M4** trong checkpoint này. Windows đã
kiểm tra bằng Python 3.14.5 / Node 24.16.0; hướng dẫn dùng Python 3.12 từ Homebrew
và Node 24 arm64, cần kiểm tra thực tế trên Mac. Không chạy qua Rosetta.
Nếu chưa có Homebrew, cài theo [hướng dẫn chính thức](https://brew.sh/).

```sh
uname -m
sw_vers
brew install python@3.12 node@24 ffmpeg
export PATH="$(brew --prefix node@24)/bin:$PATH"
python3.12 --version
node -p 'process.version + " " + process.arch'
command -v ffmpeg
command -v ffprobe
ffmpeg -version
ffprobe -version
ffmpeg -v error -f lavfi -i anullsrc=r=24000:cl=mono -t 0.1 -f null -
```

`uname -m`/Node phải là `arm64`. Homebrew có công thức
[Python 3.12](https://formulae.brew.sh/formula/python@3.12),
[Node 24](https://formulae.brew.sh/formula/node@24) và
[FFmpeg](https://formulae.brew.sh/formula/ffmpeg). Setup này cần mạng cho dependencies;
archive không phải bộ cài offline. Không có paid API hoặc model download tự động.


Tạo venv mới trên Mac; Python nêu rõ venv không phải thư mục có thể chuyển giữa

## Chrome và Remotion

Remotion hỗ trợ macOS arm64, có thể tải Chrome Headless Shell; xem
[tài liệu Chrome chính thức của Remotion](https://www.remotion.dev/docs/miscellaneous/chrome-headless-shell).
Checkpoint không kèm browser binary. Có thể dùng Google Chrome **đã cài trên Mac**:

```sh
test -x '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
export REMOTION_BROWSER_EXECUTABLE='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome'
```

Nếu Chrome chưa tồn tại, cài bản arm64 riêng trước; không để renderer tự download
không được chú ý. Repo đã đọc `REMOTION_BROWSER_EXECUTABLE` trong config, không
cần hardcode path vào source. Không cần browser renderer để chỉ verify/read state
hoặc mở Studio UI. Với render sau này, kiểm tra macOS/browser/Remotion compatibility
và memory trên máy thật; không suy ra tốc độ hay chất lượng render M4 từ test Windows.

sau verifier không cần SAPI trên Mac; không đổi voice provenance hoặc measured hash.

hash của WAV đã chuyển. Đừng tạo narration mới chỉ để mở review.

Repo hỗ trợ `macos_say_tts`; xem các voice thực đã cài bằng:

```sh

```

Chỉ chọn voice đúng ngôn ngữ đã có. Apple có thể yêu cầu tải thêm voice khi chọn
voice chưa cài ([Apple voice settings](https://support.apple.com/en-gb/guide/mac-help/mchlp2290/27/mac/27));
checkpoint không thực hiện download. Piper cần local model `.onnx` + `.onnx.json`
đúng ngôn ngữ; Korva cần runtime/model assets riêng, chưa chuyển và chưa xác minh
trên M4. Không dùng tiếng Anh thay tiếng Việt hoặc tự fallback paid provider.

Đổi voice/provider tạo waveform và duration mới: phải measured narration mới,
retiming mới và staging candidate/approval mới. Không overwrite WAV/bundle cũ hoặc
