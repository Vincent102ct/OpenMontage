# P3.0 — synthetic Stickman Horror renderer proof

Technically accepted on 2026-10-23 for scoped publication on `coding`, based on
the local MP4, actual-frame verification and regression tests.
Baseline: `coding`, `90e3558f9e3f2e7365bf83835fa3535fa56842da`.
Visual-artistic acceptance and subjective listening remain pending. Acceptance
covers this renderer proof only; it does not approve or start the real story.

## Implementation

`Actor.tsx` adds optional `stickman_horror` body/hands over the existing seekable
`motion.ts` two-bone IK joints. Thin jointed limbs, outlined circular head, face
tracks, small hands and floor shadow replace the filled clothing only when
selected. Default `cartoon` output remains identical to the pre-change SVG
hashes at three historical fixture timestamps. The IK solver is unchanged.

`StoryVideo.tsx` carries the skin through both actor layers. Optional
`viewport: {width: 720, height: 1280}` sets actual composition metadata. The
world scales uniformly by `height / 720`; camera center and zoom choose a narrow
world window. No stretching or rotation. Default viewport remains 1280×720;
StoryAction and StoryEpisode metadata remain unchanged. Camera bounds use the
actual aspect ratio. Portrait captions/inserts use portrait margins.

The synthetic fixture in `tools/character/stickman_preview.py` contains one
anonymous apartment and one actor: hold, scrape/flinch/head-gaze turn, planted
walking steps, then reach/hold near a closed door. SVG room, door and window stay
fixed in world space. Camera moves 10 world pixels and zooms 3.5%. No source story
is read. Explicit `audio_mode: "sfx_only"` requires empty narration; default
narrated packages still require exact source text and action links.

`procedural_sfx` adds a seeded furniture-scrape recipe. Room tone, scrape and
footsteps are generated locally as 48 kHz WAVs, then mixed by existing Remotion
Audio/Sequence tracks. Footfalls are quantized to the nearest frame of the
existing walk generator's landing times. There are no sampled assets, network
audio, model downloads or narration. Provider cost: $0.

## Reproduce with installed dependencies (PowerShell)

From the repository root, ensure `ffmpeg`, `ffprobe` and `node` are visible to
Python (`shutil.which`). On Windows a WinGet alias visible to PowerShell alone
may not suffice; prepend the installed FFmpeg **bin directory** to this session's
PATH. Set the path to an already installed Chrome:

```powershell
$env:REMOTION_BROWSER_EXECUTABLE = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
.\.venv\Scripts\python.exe scripts/stickman_horror_preview.py
node tests/tools/stickman_browser.cjs
```

The script calls registered `procedural_sfx → character_rig_renderer →
video_compose` tools, using the existing Remotion atelier route. It fails when
local executables are missing. It does not install or download dependencies.
The fixed ignored project is `projects/p30-stickman-horror-preview/`; an existing
directory without its matching synthetic scope marker is rejected. This command
only regenerates that proof. Composer staging uses its own ignored directory
`remotion-composer/projects/p30-stickman-horror-preview/`.

Outputs: `preview.mp4`, eight `frames/frame_*.png` images (0, 1.2, 1.8, 3.2, 5.2,
6.6, 8.4, 9.9 seconds), `contact-sheet.png`, `horizontal-cartoon.png`,
`validation-report.json`, `chrome-qa.json`, `skeleton-qa.json`, original synthetic
props/timeline and registered-tool handoff/render reports. Frame extraction
reuses `frame_sampler`; Pillow assembles the contact sheet.

## Visual review and limits

Actual start/reaction/walk/end frames and the horizontal still were inspected.
The stickman silhouette, flinch, gaze/head tilt, step changes and reach are
visible. No detached joints, teleportation, hidden main action, text slides or
layout drift were observed in sampled frames; all-frame geometry checks add
coverage between those samples. The slightly bent-knee walk remains stylized.
The hand stops near the door; grasping/turning its knob and opening it are not
part of this sample. Much of the upper frame is intentionally empty wall.

Synthesized scraping is a simple effect rather than recorded Foley. Playback
was muted for the automated browser check. Audio presence, timing and clipping
are measured; subjective listening and human visual acceptance remain pending.
No readiness claim for the private pilot follows from this renderer proof.
