## Result and human feedback

**Technical evaluation goal met:** Microsoft An, KorvaTTS and VieNeu-TTS v3 Turbo
all generated real WAVs on this Windows CPU using the same original text. No paid
API or hosted inference. User replied **“Ưu tiên B”** after receiving listening links;
B maps to **KorvaTTS / hoang_nam**. This is an overall listening preference, not a
per-criterion score, verified transcript fidelity, genre-by-genre judgment or
production approval. In the follow-up acceptance gate the user also accepted
five specifically requested Korva candidate locations; whole-transcript
pronunciation/timecodes remain pending. See the acceptance section below.

Recommend **Korva / hoang_nam for the next narrative listening evaluation**, based
on this preference and measured CPU feasibility. Commercial publication needs
upstream data/voice-rights clarification first. VieNeu has a clearer publisher
statement permitting monetized output from bundled presets, but was not the
user's preferred sample. No new model is promoted into the production selector.

Windows M1.1 EN/VI rendering remains technical PASS. Its full-video Vietnamese
pronunciation and macOS real-machine render gates remain as documented in
`docs/WINDOWS_M11_HANDOFF_2026-10-22.md`; the short M1.2 preference does not close them.

## Measured results

| Provider | Speech duration | Inference | RTF | Load | Sampled peak tree RSS |
|---|---:|---:|---:|---:|---:|
| An | 46.018 s | 3.715 s | .081 | 1.302 s | 191 MiB |
| Korva | 48.174 s | 26.136 s | .543 | 3.173 s | 563 MiB |
| VieNeu | 33.950 s | 12.933 s | .381 | 4.351 s | 1467 MiB |

RTF is synthesis wall seconds / measured audio seconds, excluding initialization.
An includes native host startup and normalization; neural timing stops before
WAV writing. RSS sums parent and children every 50 ms; shared pages may be counted
twice and short peaks missed. Single final trial per provider, no controlled
throughput guarantee or GPU/VRAM measurement. All three satisfy the 30–60 s target.

Korva float outputs peaked above 1.0. Initial direct PCM16 export clipped; those
files/logs were archived in `research/first-pcm-export/`. Final benchmark retains
FLOAT audio and uses static peak gain before integer conversion; no SDK patch.
Final raw PCM16 extreme-sample count is zero. No compressor, limiter, tempo,
pitch, denoise or silence trimming. Matched clips use mono 48 kHz / PCM16 static
gain to -20.2 LUFS; maximum error .01 LUFS, highest true peak -2.24 dBTP.

## Listening artifacts and reproduction

Local evaluation root: `projects/m12-vietnamese-tts-review/` (Git ignored).
Open `review/INDEX.html`. `A_all.wav` = An, `B_all.wav` = Korva, `C_all.wav` =
VieNeu. Durations including two 1 s gaps: 48.018 / 50.174 / 35.950 s.
`ABC_*.wav` compares each passage A→B→C with .8 s gaps. Original/normalized text,
native/raw/matched WAVs, cue metadata, technical CSV, blank score sheet, recorded
user preference, license review, exact versions and SHA256SUMS are included.
Pilot files are retained separately and excluded from final comparisons/manifest.

To reproduce on another Windows machine, copy the benchmark scripts plus
`review/metadata/*-freeze.txt` (do not copy venvs); place scripts in the same
`projects/m12-vietnamese-tts-review/` path in this baseline checkout. Install
Python 3.11 for the current user if absent, without administrator/security changes.
The production setup and An voice discovery remain in `docs/WINDOWS_STORY_TO_VIDEO.md`;
do not assume An exists on another machine. The harness fails explicitly if absent.

```powershell
# From OpenMontage root. Python 3.11, production .venv, FFmpeg and native An prerequisite.
$bench = 'projects/m12-vietnamese-tts-review'
New-Item -ItemType Directory -Force "$bench/research", "$bench/logs", "$bench/review" | Out-Null
foreach ($name in 'korva','vieneu','qa') {
    py -3.11 -m venv "$bench/envs/$name"
    & "$bench/envs/$name/Scripts/python.exe" -m pip install --only-binary=:all: -r "$bench/review/metadata/$name-freeze.txt"
    if ($LASTEXITCODE) { throw "Environment setup failed: $name" }
}
# Original installs: korvatts==0.1.3 + psutil==7.2.2; vieneu==3.8.3;
# optional QA faster-whisper==1.2.1. Freeze files pin transitive dependencies.
$env:M12_FFMPEG_EXE = (Get-Command ffmpeg -ErrorAction Stop).Source
& "$bench/envs/korva/Scripts/python.exe" -X utf8 "$bench/prepare_models.py"
& .venv/Scripts/python.exe -X utf8 "$bench/benchmark.py" prepare
foreach ($provider in 'microsoft-an','korva','vieneu') {
    & "$bench/envs/korva/Scripts/python.exe" -X utf8 "$bench/benchmark.py" monitor $provider
    if ($LASTEXITCODE) { throw "Inference failed: $provider" }
}
& "$bench/envs/korva/Scripts/python.exe" -X utf8 "$bench/build_comparison.py"
Start-Process "$bench/review/INDEX.html"
```

Preparation requires internet to fetch pinned public models; synthesis does not.
`prepare_models.py` recreates absolute local manifest paths after moving machines.
Optional ASR requires downloading the pinned Whisper-small files and recreating
`research/asr-local-path.json` locally; it is not needed to synthesize or listen.
`finalize_review.py` packages original-machine evidence and verifies its saved WIP
snapshot/vendor checkouts; do not apply that snapshot to unrelated dirty worktrees.
Archive/copy the ignored evaluation directory if preserving these WAVs across machines;
neither WAVs nor benchmark scripts are automatically available from a Git clone.
