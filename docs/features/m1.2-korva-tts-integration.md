## Goal and scope

Story Markdown → analyze → **Korva narration** → Story Planner → Remotion → MP4 +
subtitles + QA in one command, fully offline, no paid API, no per-story WAV preparation.
Out of scope: other TTS models, voice cloning, Planner/renderer/Remotion changes, M2.

## Interface

```powershell
.\.venv\Scripts\python.exe scripts/story_to_video.py <story.vi.md> --analyzer rules `
    --tts-provider korva [--voice hoang_nam] [--rate 1.05] `
    [--korva-python <py311 with korvatts>] [--korva-assets <snapshot with onnx/ + voice_styles/>] `
    [--project-id <id>] [--no-render | --dry-run]
```

| Option | Korva meaning |
| --- | --- |
| `--tts-provider korva` | Korva only; any failure stops the run (no fallback voice) |
| `--tts-provider auto` | Korva first for `vi` when an install is discovered; else native → Piper. EN unchanged |
| `--voice` | Bundled preset name; default `hoang_nam` |
| `--rate` | SDK `speed`, 0.5..2.0, default 1.05 |
| `--korva-python` / `OPENMONTAGE_KORVA_PYTHON` | Interpreter with `korvatts` |
| `--korva-assets` / `OPENMONTAGE_KORVA_ASSETS` / `KORVATTS_ASSETS_DIR` | Local checkpoint snapshot |

Without flags/env, discovery uses the M1.2 benchmark install
(`projects/m12-vietnamese-tts-review/envs/korva`) and Hugging Face caches, preferring
revision `e5c8c218e93c1d8daa53bfe0e62b8fbc5a5e991d`. Never downloads.

## Architecture

| Component | Responsibility |
| --- | --- |
| `tools/audio/korva_tts.py` (`korva_tts`, provider `korva`) | Discovery, checkpoint/preset hashing, input validation, worker lifecycle, FFmpeg normalization to mono 24 kHz PCM16, ToolResult with generation metrics |
| `tools/audio/korva_worker.py` | Runs in the Korva interpreter only. `--probe` lists presets/versions without loading ONNX; default mode loads the model once and answers JSON-line requests |
| `tools/audio/local_narration.py` | `korva` candidate, Vietnamese-only validation, settings/model metadata; `auto_skipped` diagnostics excluded from cache keys |
| `scripts/story_to_video.py` | CLI flags; `narrate()` holds `tts.session()` for providers that offer it; `metadata.narration` summary in render report |

Process boundary: pipeline Python 3.14.5 ↔ Korva CPython 3.11.16 (korvatts 0.1.3,
onnxruntime 1.31.0, CPUExecutionProvider). Startup errors, synthesis exceptions,
process exit, protocol corruption and timeouts (180 s start, 900 s request) become
`ToolResult(success=False)`, and `narrate()` stops the run. Native stdout is moved to
stderr so it cannot corrupt the protocol channel.

## Audio contract

- Same inference call and settings as the benchmark: `hoang_nam`, `vi`, 32 steps,
  speed 1.05, 0.3 s between SDK chunks, seed 20261022, CPU, 6 threads (≤ CPU count).
- Text sent verbatim per beat. The SDK's sentence chunker keeps chunk order;
  canonical narration and subtitles never change.
- Leading/trailing frames below -45 dBFS are trimmed to a 0.1 s pad (leading
  silence skewed the planner's verb-to-time mapping, e.g. 0.72 s before "Lan bước ra
  đường."). Interior pauses and every audible tail segment are kept.
- Static gain 0.6 for all beats; lowered only when a beat would exceed -1 dBFS.
  No limiter/compressor/tempo/pitch processing.
- Duration = PCM16 samples / 24000 after normalization; remeasured on every run,
  including cache hits.
- Cache key: provider/tool version, text, settings, runtime paths, checkpoint SHA256
  (all six ONNX/config files), preset SHA256, SDK version and the worker's PCM export
  policy. A different provider (e.g. Microsoft An) never reuses Korva WAVs, and vice versa.

## Known limits

- Not a publication-quality claim; human listening approval pending.
- Korva can drop words in short sentences. In the second story, ASR does not hear
  "uống" (b04), "một lúc" (b07) or "một" (b02); the unmodified SDK call produces the
  same audio, so the pipeline did not cause it. Whisper hypotheses, not confirmed.
- ASR substitutions to check by ear: xách, lộp độp, trạm, sũng, sững, xe buýt (story 1);
  cốc, chật, chai, có thể, "bốn mươi mét vuông" (story 2).
- b09 of story 1 keeps a detached vocoder tail burst ~0.7 s after the words (the SDK's
  `clean_tail` misses long pauses). It lowers that beat's gain to 0.513 (~1.4 dB
  quieter); beat RMS spread 6.86 dB. Removing such bursts automatically was tried
  and rejected because it cut real words.
- Per-machine float differences are possible; RTF depends on CPU. Only `hoang_nam`
  evaluated; other bundled presets are accepted but unreviewed.
- The new-machine setup snippet in the Windows guide has not been run on a second machine.
- License: publisher states Apache-2.0 (code, weights, presets); training data
  (PhoAudiobook) commercial rights and preset speaker consent are not independently
  verified. Not a technical blocker; recorded for the user.
