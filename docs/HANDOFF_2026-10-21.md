## 3. Architecture and entry points

```
story.md ─► story_analyzer (rules VI/EN, optional local Ollama fill-only)  tools/story/story_analyzer.py, lexicon.py
         ─► macos_say_tts per sentence (measured WAV durations)             tools/audio/macos_say_tts.py
         ─► story_planner (shots, camera, skeletal tracks, props, SFX)      tools/story/story_planner.py, locations.py
         ─► procedural_sfx                                                  tools/audio/procedural_sfx.py
         ─► character_rig_renderer story_video route → validate + package   tools/character/story_video.py
         ─► video_compose (atelier) → Remotion composition StoryVideo       tools/character/remotion/StoryVideo.tsx
         ─► story_qa (probe, decode, cuts, loudness, motion, keyframes)     tools/story/story_qa.py
```

- CLI: `scripts/story_to_video.py` (only sequences registered tools; no creative logic).
- Rig and IK: `tools/character/remotion/motion.ts`, `Actor.tsx` (shared with the pilot, unchanged by M1/M1.1).
- Pilot/episode path (still supported): `tools/character/story_motion.py`, `remotion/Scene.tsx`, `Episode.tsx`, `shots.ts`, `examples/story-to-action/`.
- Design and capability tables: `docs/features/story-to-video-pipeline.md`. Decisions: `DECISIONS.md`. Source map: `SOURCE_MAP.md`. History and measurements: `WORKLOG.md`. Plan: `ROADMAP.md`.

## 4. CLI

```sh
.venv/bin/python scripts/story_to_video.py path/to/story.md [--analyzer auto|rules|ollama] [--draft] [--no-render] [--project-id ID]
```

Input: UTF-8 Markdown/text, optional `# Title` first line, blank-line paragraphs, Vietnamese or English.
Output: `projects/<file-stem>-auto/renders/final.mp4` plus `artifacts/` (analysis, plan, timeline, edit decisions,
QA and render reports), `assets/audio/`, `assets/subtitles.srt`, `renders/keyframes/`, `renders/contact_sheet.jpg`.
`--no-render` stops after the validated Remotion package (fast check, no browser).

## 5. Setup from a clean clone (macOS, Apple Silicon tested)

```sh
git clone https://github.com/Vincent102ct/OpenMontage.git && cd OpenMontage && git checkout coding
python3.10 -m venv .venv            # 3.10.21 was used; >=3.10 required
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
(cd remotion-composer && npm ci)    # Node 26.0.0 was used; Remotion 4.0.484 from package-lock.json
brew install ffmpeg                 # FFmpeg 8.1.1 was used (ffmpeg + ffprobe on PATH)
say -v '?' | grep -E 'Linh|Samantha'   # both voices must be listed (see 8)
# optional local LLM:
brew install ollama && ollama serve &  && ollama pull qwen2.5:7b-instruct
```

Remotion downloads its headless browser on the first render. `remotion-composer/remotion.config.ts` has no machine
paths; set `REMOTION_BROWSER_EXECUTABLE` / `REMOTION_RENDERER_PORT` only if a specific browser or port is needed.
When the agent sandbox is used, rendering (local server + browser) and macOS speech must run outside the sandbox.

## 7. Ollama (optional)

- Runtime `ollama 0.40.7` (Homebrew), model `qwen2.5:7b-instruct`, ID `845dbda0ea48`,
  weights `sha256:2bada8a7…3730` (4.68 GB). Re-download: `ollama pull qwen2.5:7b-instruct`.
- `--analyzer auto` uses it when `http://127.0.0.1:11434` answers, otherwise rules only; `--analyzer rules` never calls it.
- Merge is fill-only: on both test stories the model accepted 0 actions, so the videos do not depend on it.

## 8. TTS

- `macos_say_tts` only (offline, $0): Vietnamese **Linh vi_VN rate 145**, English **Samantha en_US rate 165**.
  The adapter fails closed if the voice/locale is missing or the WAV is empty.
- No Windows/Linux voice is wired into this pipeline. `windows_sapi_tts` / `piper_tts` exist in the repo but are not
  selected by `scripts/story_to_video.py`; on Windows the CLI fails at the narration step, and there is no option
  yet to supply pre-recorded WAVs.
- The handwriting font of written-item inserts is macOS "Bradley Hand" with cursive fallbacks.
